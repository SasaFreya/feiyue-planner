# 飞跃日程规划本

设计想法与功能进展见 [产品设计想法](docs/产品设计想法.md)。已做和未做的想法都保留，并持续更新状态。

根据纸本照片制作的春日风私人网页版，包含：
- 周计划：周一至周日、每天五项待办、5–24 点时间轴、每日随记，最右侧增加自由页。
- 自由页：可增加的待分配事项与独立自由书写区，按周保存。
- 移动事项：dnd-kit 鼠标/触屏拖动、点选目标分配、已有事项交换、撤销并保护后续编辑。
- 月度事项：四个季度、每月六项可勾选事项、小日历。
- 年度纵览：十二个月 × 31 日，无效日期禁用，点击星期可跳转周计划。
- 全年日历：点击日期跳转，已有记录的日期带标记。

电脑显示完整七列，手机可横向翻看每天。内容通过同源 API 保存到 D1；本地预览使用本机 SQLite 数据库，不是浏览器缓存。数据尚未发布到线上。

## 本机运行

已安装依赖。使用 `npm run dev -- --host 127.0.0.1`，打开终端输出的本地地址。当前预览地址是 http://127.0.0.1:5173/。

`npm run build` 生成 Worker 构建。`npm run db:generate` 生成数据库迁移。生产发布需要恢复 Sites 插件的发布组件，然后继续使用 `.openai/hosting.json` 中已注册的 project_id；不要重复创建网站。

本地数据库迁移已应用，数据库在忽略的 `.wrangler/state` 中。预览测试记录已清空，生产数据库尚未初始化或写入。发布前将使用现有迁移初始化生产数据库。
