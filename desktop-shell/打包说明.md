# 飞跃桌面构建

正式桌面源码在 `desktop-shell/`，共享业务模块在 `features/`。`desktop/main.swift` 是早期独立清单原型，正式版本已替换为 Electron，不再用于构建正式应用。

- `npm run desktop:build`：构建离线 React 界面、主进程和空数据发行种子。
- `npm run desktop:package`：打包 Apple Silicon Mac 应用，需已安装 Electron 38.8.4 运行时。
- `npm run test:planner`：共享事项、排序、计时、SQLite 迁移与 loopback API 测试。
- `npm run build`：检查网站生产构建。

构建器读取现有 `.wrangler/state` 纸本 / 项目库，放入 `desktop-build/seed.json`。这是本机私人迁移包，已忽略，不要把构建包公开分发。公开演示包应改用空种子。首启后数据来自 Application Support 内的 SQLite，重新构建和升级不会重新导入或覆盖现有库。

正式程序启动后只监听 `127.0.0.1:17863`，静态界面与共享 API 同源。浏览器可打开此地址，与桌面大小窗口共享数据。不要继续向旧 5173 预览库写入；它不是当前本机数据库的镜像。手机 / 云端跨设备同步仍未实施。

本机临时签名版本不含 Apple 开发者公证；其他机器发行需单独构建、签名、公证和迁移验收。

## 下一次用户要求更新包时（2026-10-16 约定，尚未执行）

1. 正常退出旧 App/本机数据服务，备份 `~/Library/Application Support/FeiyuePlanner` 全目录，保留 SQLite、可能存在的 WAL/SHM、迁移与自动备份；备份与应用目录分开保存。
2. 新版保持同一数据路径，已有库优先，不能重新导入 seed 覆盖旧数据。现有测试已验证新种子不会覆盖已有事项、笔记、计时和显示偏好；仍需实际新包验收。
3. 只维护一个正式 `.app` 入口。先启动新版核对数据，再清理多余旧 App 和 desktop-release 的冗余发行副本；原用户数据库和备份不在清理范围。旧程序停止运行后才处理旧文件。
4. 记录最终版本、入口、备份位置和清理清单。用户这次询问为后续打包约定，没有触发立即打包或删除旧版。

## 2026-10-20：公开下载安装包

用户已授权公开源码与下载安装包。0.3.1 起构建器固定生成空 seed，不再读取开发机器 .wrangler 数据库；以上“本机私人迁移包”描述是历史流程。发布包只支持 Apple Silicon Mac，未公证；现有用户库继续优先，不会被空种子覆盖。GitHub Releases 提供 ZIP，解压后将 .app 拖入应用程序。Windows、Intel Mac 安装包尚未提供。
