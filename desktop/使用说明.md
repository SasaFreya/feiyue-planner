# 飞跃日程规划本 · 完整桌面版

双击本目录的「飞跃日程规划本.app」。这次是完整桌面版，原网页功能已经进入大窗口，小清单共用同一份数据；不需要手动打开终端、启动开发服务器或连接互联网。

## 常用操作

- 头像：点击展开 / 收起今日清单，拖动改变位置；外圈是今天的完成比例。
- 小清单：填写事项，拖动左侧把手调整先后，打勾完成，点彩色圆点选择项目。开始 / 暂停记录真实用时。
- 「打开完整规划」：进入完整窗口。侧栏提供今天、日历、纸本与原有功能、项目分类、时间记录。
- 原功能：在「纸本与原有功能」中继续使用原年 / 月 / 周、自由页、年度纵览、项目任务池、安全线、自动安排、旧统计、回响导出、设置反馈。
- FullCalendar：日 / 周 / 月 / 年 / 列表切换。拖事项更改日期 / 时间，拖边缘调整计划时段。点击事项在右侧编辑。
- 项目：自定义名称和纯色，日期可选；归档保留记录。移除分类会将事项变为未分类，保留历史时间。
- 时间记录：日 / 周 / 月 / 年 / 自定义范围，按事项或项目查看，展开查看计时片段，可补录、修正、删除并撤销，支持 CSV。
- 手动顺序独立于计划时间；排序不会改计时和项目。纸本拖动、日历拖动和清单操作都引用同一事项。
- 主题：春日彩色 / 简约共享设置。小清单底部可换认真头像 / 蓝色小球。

关闭大窗口、收起小清单时计时继续；菜单栏退出或电脑睡眠会暂停。异常退出后，下次启动将按最后保存的心跳暂停，记录标注待核对，可在时间记录中修正。

## 数据与网站关系

正式本机数据：`~/Library/Application Support/FeiyuePlanner/planner.sqlite`。

首次启动会导入构建时的原网页本机数据与旧 Swift 清单，并建立 `migration-backup.json`。同名事项保留各自身份，不随意合并；已导入的数据不会在下次启动重复导入。原纸本随记 / 月目标 / 年记录保留原样，旧预计分钟不冒充真实计时。

菜单栏「在浏览器打开同一规划本」访问 `http://127.0.0.1:17863`，与大窗口、小清单共享数据。请优先使用这个入口。更新后的 5173 开发预览也代理到桌面数据服务，需应用运行；旧的预览服务需重启后才能启用此代理。尚未实现手机 / 云端跨设备同步。

侧栏可导出完整 JSON 备份；菜单栏可打开数据和迁移备份文件夹。备份 SQLite 前建议正常退出应用，并连同可能存在的 `-wal`、`-shm` 文件一起保留。当前完整 JSON 导出可供保存，尚无可视化导入按钮。

## 运行与验证边界

本机构建为 Apple Silicon Mac，程序临时签名，尚未办理 Apple 公证。复制整个 `.app` 到“应用程序”即可保留为常用入口；本目录 `.command` 只是备用启动方式。

已通过共享数据、排序、计时、迁移与来源校验测试；已实际验证浏览器同界面的添加、计时、勾选、鼠标拖动排序、刷新恢复、项目选择、FullCalendar 拖日期与时间及大小清单共享状态。电脑睡眠事件和悬浮头像实际拖动尚未做设备级验收。

源码与构建：`desktop-shell/`；旧 Swift 源码仍保留为原型历史。重新打包使用 `npm run desktop:package`，不要运行旧 `desktop/build.sh` 构建正式版。

## 数据保管现状
正式数据位于 `~/Library/Application Support/FeiyuePlanner/planner.sqlite`。SQLite 使用事务和 WAL；首次迁移留有 `migration-backup.json`。数据仅在本机共享，目前没有云端同步，也没有应用级加密。
源码已加入 `backups/daily-YYYY-MM-DD.json`（每日首次使用前的快照）和 `backups/latest.json`（最近一次非心跳更新快照），采用临时文件写入后重命名。此代码尚未进入既有已打包 App，须下次运行新版本机服务后才生效。
完整 GUI 左下角可以导出完整 JSON 备份，建议保留副本在另一块磁盘。复制运行中的 SQLite 时不能只复制主文件而遗漏 WAL；优先使用导出。当前尚无可视化恢复/导入入口，恢复须先保留现有库再进行人工处理。
