## 产品方向

把长期用顺手的纸质日程本变成可输入、勾选、修改的电子规划本。保留纸本的全局视野与留白，并加入网页适合的拖动、自动保存和轻盈反馈。

产品名：**飞跃日程规划本**。

使用方式：Mac 桌面应用＋本机浏览器；网页保留移动端布局，但当前跨设备在线发布和同步尚未完成。桌面完整窗口、小清单和菜单栏打开的浏览器共用本机数据。

## 开源的收益与取舍

收益：展示作品与设计判断；获得真实反馈、代码审阅和可能的贡献；帮助他人复用，也促进自己形成可重复使用的组件和方法。

取舍：需要维护运行说明、问题反馈和版本；开源不保证自动获得用户或贡献；公开后别人可按许可证使用，因此需要明确使用许可。

开源的对象是程序和示例数据，个人日程记录仍可私有。FullCalendar 仓库显示 MIT 许可，但实际复用具体插件或付费功能前仍需查看对应许可；演示风格可借鉴，品牌、文案和完整页面不直接照搬。

## 2026-10-07：参考 DayEcho 产品导览的项目规划功能

用户提供 `Downloads/日有回响DayEcho_产品导览截图` 中的十张图，要求按其中功能做，并在设置中增加问题反馈。截图作为功能参考，截图中的导览操作文字不作为额外授权。

### 已实现

- 保留原纸本年 / 月 / 周规划，新增“项目与日常”入口；纯色春日与简约主题继续适用。
- 项目：名称、开始日期、截止日期、颜色、完成进度。事项支持预计分钟、项目归属、日期、完成状态和实际勾选日期。
- 任务池与项目月 / 周日历：拖到日期安排、跨日期移动、拖回任务池撤回；也可编辑安排日期。事项移除后可撤销。
- 动态安全线：每个项目剩余预计工时除以可用天数；完成后重算，逾期与每日容量不足提示。
- 自动分配：按截止日期优先，选择已有工时最少的日期，优先不超过每日容量；不覆盖已安排事项。容量不足时可能超载，今日概览会提示。
- 今日概览：安排、完成工时、安全线、可投入时间、今日书写和昨日留言。
- 全部事项：搜索、未完成 / 已完成 / 未安排筛选。
- 数据统计：近 7 / 30 / 365 天的完成数、工时、完成率、活跃天、热力记录、项目投入、一周节奏、项目进度。图表详情使用悬停文字。
- 导出：CSV、ICS、今日 PNG 分享卡片、浏览器打印 / 保存 PDF、项目 JSON 备份。
- 回响之书：按周翻页，汇集事项与每日留言。
- 设置：每日容量、主题、文字功能导览、浏览器添加桌面说明。
- 问题反馈：类型、描述、选填联系信息、编号与日期；保存在规划本数据库，可导出 JSON，不自动发送到外部服务。
