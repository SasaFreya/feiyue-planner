# 功能库与按需接入规划

日期：2026-10-16。用户认可此前开源候选，希望规划后接入，同时要求自己选择展示的功能，不常用的集中收纳，并能从收纳页单独进入。

## 体验规则

- 默认侧栏只有今天、日历、笔记与心愿，以及固定的功能库；设置放在底部。
- 功能库展示所有已可用的独立功能，有一句用途说明、搜索、打开和“放到侧栏/常用”开关。
- 设置中的“常用功能”可统一选择。全部取消时仍保留功能库和设置，避免失去找回入口；“恢复简约入口”恢复三个默认功能。
- 收起只改变入口，不删除事项、项目、笔记、计时或历史；收起的功能仍可打开。正在计时不因导航切换停止。
- 侧栏项目筛选默认收起，可在设置中单独打开。每日清单的项目圆点和日历的项目筛选继续可用。
- 保持纯色、不透明表面与轻量分组列表，不把每个工具做成抢眼大卡片。

## 本轮已实现

1. 统一功能清单：今天、日历、项目与分类、笔记与心愿、时间记录、容量与分配、预计与完成、导出与回响之书、使用反馈。
2. 常用开关在功能库和设置中联动，写入现有共享 settings，与其他入口使用同一本机数据。
3. 原“回顾与工具”里的工具成为独立页，不再藏在笔记页的第二层导航。笔记保留原数据键；每日可投入分钟统一到设置，反馈页聚焦记录反馈。
4. 正式接入已安装的 MIT 组件 `react-resizable-panels`：日历宽区域可调整左右栏，支持键盘；宽度偏好持久化。内容区域不足 780px 时使用上下布局，不将日历挤成细列。
5. 日历、项目、时间记录及旧回顾工具使用动态导入，进入时加载并按页挂载。历史纸本源码移到 `features/legacy/paper-planner.tsx` 保留参考，从当前入口构建依赖中移出。没有删除或重新导入旧纸本数据。
6. 所有变化仅在源码/开发预览；未更新安装版、未重新打包、未清理旧应用。

按需加载减少初始加载代码，不代表退出功能后浏览器会立即卸载所有已加载代码，也不是系统 RAM 占用的测量结论。

## 开源采用清单与后续顺序

| 候选 | 当前状态 | 下一步与默认展示规则 |
| --- | --- | --- |
| FullCalendar Standard | 已接入并继续维护 | 唯一日历入口；保留当前版本，先解决密度与编辑体验 |
| dnd-kit | 已接入并继续维护 | 用于清单排序；日历内部拖动仍归 FullCalendar，避免两套逻辑争抢 |
| react-resizable-panels | **本轮已接入日历** | 实际浏览器验证键盘调整与窄窗回退；原生 Mac 指针拖动待设备验收 |
| rrule | 已选为后续周期日期计算候选，尚未安装/接入 | 可靠计时与恢复闭环之后接入周期事项；默认作为日历编辑的可选项，而非增加一堆侧栏入口；须先定义系列、实例、例外日期和独立完成/计时 |
| Super Productivity | 已调研，参考设计；未复制源码 | 借鉴任务生命周期、时间盒与异常恢复；保留现有 React 产品，不引入第二套 Angular 应用 |
| solidtime | 已调研，参考交互；未复制源码 | 借鉴实际时间表和汇总；不引入团队/计费服务。未来复制源码前核对 AGPL 义务 |
| ActivityWatch | 已列入未来可选集成，**尚未连接或启动** | 若实施，作为功能库里的“电脑活动回顾”，用户主动启用后读取本机数据，默认不常用、不自动启动采集；与手动计时区分来源并避免重复累计 |

官方来源与许可证核对见 [阶段总结与开源复用规划](阶段总结与开源复用规划-2026-10-15.md) 第 4 节。本轮没有新一轮网络调研，也没有把参考应用写成已经集成的组件。后续每接入一个模块都登记真实状态，验收后才放入功能库，不放无法打开的假入口。

优先顺序：本轮完成“入口可收纳 + 可调日历分栏”；随后继续处理备份可恢复、快照提交一致性、后台计时；再加入周期事项与可选活动回顾。新增模块沿用同一任务/计划/实际时间模型，不各自维护副本。

## 验证

- TypeScript 检查通过，15 项模型/SQLite/本机 HTTP 测试通过。新增覆盖时间改记、旧数据升级保留、隐藏所有功能仍不改变业务数据、设置校验与偏好重开。
- 临时库浏览器验证：默认简约导航、设为常用、刷新恢复、收起后仍可独立打开时间记录和容量工具、日历分栏键盘调整、900px 窄窗上下排列且无横向溢出。
- 界面生产构建输出到 `/tmp/feiyue-ui-20261016-validation` 验证分块成功；没有执行桌面打包或改写正式 App。
- 时间修正与常用偏好在临时库测试，没有往用户真实库添加测试事项或更改真实计时。
- 待验证：原生 Mac 的分栏指针拖动、多原生窗口实时显示及新版本更新清理流程。没有将浏览器验收写成设备级验收。
