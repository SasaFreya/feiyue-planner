04 / 你的记录，在你手里

下载的是工具，
带走的是自己的记录。

桌面日程保存到本机 SQLite。发行包从空白开始，不包含作者的日程、数据库和备份。

完整窗口、桌面小清单和应用打开的本机浏览器共享数据。你可以导出备份，也可以查看本机快照。

桌面与私人云端数据目前独立，不会自动上传或合并。本页面只介绍产品和提供下载，不存放你的日程。

05 / 你可能想知道

开始之前。

需要账号，或一直联网吗？

桌面核心规划和计时无需登录飞跃账号，可在本机使用。下载安装包和使用部分外部连接器需要网络。

手机和电脑会自动同步吗？

目前不会。桌面本机数据库与作者的私人线上实例彼此独立。跨设备数据同步尚未完成验收；这里不是公共云端规划本。

更新时会覆盖原来的日程吗？

新版本优先读取已有本机数据，不会用空种子覆盖。更新前仍建议导出备份；当前尚无可视化完整恢复流程。

支持 Windows 或 Intel Mac 吗？

目前只提供 Apple Silicon Mac 安装包。其他平台还没有已验证的发行版本。

在哪里反馈问题、查看源码？

请到 GitHub Issues 提交系统版本、应用版本和复现步骤。应用内反馈先保存在本机，不会自动发送。公开截图前请检查文件名、账号和真实日程。源码已公开，项目整体许可证尚未指定。
